# Performance Evaluation Round 3

Round 3 records a proposed adjustment to the starting composition ratios for the next experimental round. It is based on Round 2 composition-feature and Pareto-front evidence.

Primary files:

- `performance_evaluation_report_round3.md`
- `performance_evaluation_round3.yaml`
- `performance_review_queue_round3.yaml`
- `tables/adjusted_starting_compositions_round3.csv`
- `tables/adjustment_manifest_round3.json`
- `scripts/generate_round3_starting_compositions.py`

These outputs are proposed inputs for future execution. They are not new measured, predicted, or computed performance results.
